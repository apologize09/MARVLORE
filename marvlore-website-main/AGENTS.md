# 用户的持续偏好

- 网站改动默认先保留在本地预览供用户逐步调整；仅在用户明确说“发布”“上传”或同等意思时才同步到线上（包括 here.now 和原 Sites）。预览阶段不发送登录验证码。
- 首屏卡片必须显示各项目原有图片封面，不以统一纯文字封面代替，也不遮住所有非当前项目封面。
- 首屏保留标题逐词渐显及上移、缩放；标题开始上移时卡片同步入场。卡片从右侧前方依次顺时针飞入三维椭圆环，封面先较正面渐显，沿弧线柔和转向落位；单张飞入 1.8 秒，错峰 0.13 秒。所有卡片落位并开始旋转后，背景光晕才平滑渐显。不经过中间平面圆环和变形，保留拖动与点击详情，卡片使用项目原色。
- 精选作品切片卡片默认保留低饱和冷灰蓝蒙版（原 155 版色调）；鼠标进入单张卡片范围或键盘聚焦时恢复原色，移出时恢复蒙版；点击展开的项目和详情也显示原色。此规则仅作用于作品切片组。
- Marvlore Go 作品墙保留蓝色主调卡片的原色，不给这些卡片加蒙版；其余卡片使用冷灰蓝蒙版，鼠标移入单张卡片时恢复原色、移出时重新覆盖。只随作品墙成形渐入蒙版，不改变前面的漂浮效果、逐张组合和旋转动画。
- About 品牌介绍屏的上弧卡片优先选大面积真实白色背景的素材，不能只用浅蓝或浅紫代替白底；下弧卡片选用大面积蓝色画面。保持原有方形卡片、排列和 0.4 秒入场延迟。
- 联系尾页为纯文字分栏：左侧 Get In Touch、深圳所在地与品牌介绍位于上方，右侧联系方式位于下方，正文与底部版权栏间距较小。文字入场复用创意服务区的渐显、4px 模糊与上移动效，按滚动位置可逆还原；联系方式悬停/键盘聚焦时使用服务区的小圆点提示与放大标题字切换。不使用视频、色块卡片或胶囊按钮。保留原有 Get In Touch、Let’s Talk、Drop Us A Line 与迈络真实信息、复制邮箱和返回顶部，字体沿用全站标准。

- 默认只开发、设计和验证桌面网页端。除非用户单独明确提出手机端需求，不做手机端适配、交互设计或手机尺寸测试。
- 可以保留既有响应式兜底样式，但不得因此扩大本次任务范围。
- 保留 MARVLORE 现有黑色、荧光绿、蓝色视觉语言，Apple Design 用于交互逻辑和质感。
- 各屏独立、卡片内容可替换，后续迭代优先修改相应组件和集中配置。
- 所有卡片统一使用圆角半径＝未变换尺寸的短边 × 8%。保持圆弧半径一致，不使用 CSS 的双轴百分比椭圆角；未来新卡片复用 dist/card-shape.js 或 data-card-shape。仅改变圆角，不改变卡片比例。
- 字体入口为 dist/fonts.css：中文保持 OPPO Sans；英文标题使用 Newsreader 6pt Light，按每个英文单词首字母大写、其余小写排版（首屏标语末尾 POP 保持全大写）；英文正文使用 FK Grotesk Trial Regular。全屏项目标题的中文采用较小字号、宽松字距，并与英文保持明确行间留白。
- 展开导航菜单中的英文项目名称使用 Newsreader 6pt Light，按标题规则每词首字母大写；编号、底部联系信息仍使用 FK Grotesk Trial Regular，中文仍为 OPPO Sans。
- 服务区已按用户新要求替换为黑底白字的服务列表，参考 letsplayfight 的右侧列表、左侧悬停图片与说明联动；不再使用掉落标签屏。类型依次为 Film、Animation、Web Development、Visual Design、Marvlore、CGI、AIGC、Advertising、3D Animation，英文为主、中文为辅，每项集中配置。
- 服务列表全部完整出现后，自动依次展示各项原有悬停效果（左侧图片、说明、小圆点与放大标题），每项约 2.6 秒。图片、说明与放大标题采用同一套渐显、4px 模糊变清晰与上移动效，退场同步向上淡出并模糊。鼠标悬停或键盘聚焦优先并暂停自动切换，离开后从当前项继续；离开此屏、页面隐藏或启用减少动态效果时暂停自动展示。

- Explore 到作品墙：跳过中间的环形聚拢，沿用同一批漂浮卡片的封面，逐张移动、转正并排布成弧形作品墙；不得以另一组卡片淡入替换。作品墙旋转后上滑须从当前角度逐张退回，中途反向保留当前位置和速度，入口附近小幅往返不得反复重建卡片。
